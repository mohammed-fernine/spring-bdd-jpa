# HotelBay Wiki

Welcome to the HotelBay project wiki. This wiki summarizes the behavior-driven (Cucumber) scenarios and key project references.

- Getting Started: see README.md in the repository root
- API Endpoints: documented in README.md
- Scenarios: see the pages under this wiki, starting with Scenarios.md
- CI/CD: GitHub Actions pipeline is defined in .github/workflows/ci-cd.yml
- Deployment: via Docker image + SSH to the university server

For each domain area, you will find a page listing its scenarios and steps.
